## 载体与持久状态

- `PlayerProfile` 有 avatar_id、avatar_name、nickname、avatar_confirmed、name_confirmed、profile_version。
- 以同版 AvatarConfig 的基础载体 `8002/playergirl`（星）、`8001/playerboy`（穹）为稳定身份；显示名称结合本轮明确的载体标签。昵称不作为内部 ID，也不以性别布尔值代替身份。
- BWIKI 在银狼说明“必须是你”后明确记录启用载体。编译器通过这句台词的唯一来源位置定位到 HF001 的 **135 之后**，不在程序启动时插入。
- 同时保存 MissionInfo 的 CreateCharacter 条件、文件哈希及页面位置，作为原始事件存在的交叉证据；CLI 的二次确认是 Reader UI，不声称修改游戏账号。
- 支持星 → 返回 → 穹 → 认证 → 输入中文代号 → 确认；姓名可返回重输。无效输入不改变快照。
- 限制为应用自身的 1–32 个 Unicode 字符，拒绝空白、控制、格式及换行字符；没有声称这是官方游戏限制。
- 普通剧情不能再次更换已经确认的载体；显式回溯到认证之前会恢复当时的完整状态。
- 档案、选择、事件、必要变量和审计均沿用 State/ArcSession/Save Schema 1，没有第二套存档。
- `set_story_variable` 声明需要跨章节保存的 JSON 变量；`continue_to` 仅在当前章节出口显式延续档案、这些变量和旧章节审计，验证目标包的载体定义。
  跨章节接口已有自动化测试，本轮没有扩建第二个真实章节，也未据此宣称原生跨章执行。

BWIKI 将 HF001 的 136–144 标明为等待载体选择时的可选彩蛋。现在提供查看/继续菜单；默认验证路径选择查看以保留全部来源条目。
不再把所有等待彩蛋当作必然发生的正文。跳过属于用户明确选择，相关源文仍完整保留在包内。
