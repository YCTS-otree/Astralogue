# 双击启动与 Persistent PTY

直接双击项目根目录 `Astralogue.cmd`，无需传参或先进入项目目录。可以把这个文件复制到桌面或其他文件夹再双击。启动后进入账号菜单。

启动器使用现有 `.venv`、当前 `src` 源码，工作目录自动切到项目根目录，数据包和存档均从项目读取。项目正常更新后不用重建 EXE 或修改启动文件。没有生成独立可执行程序。

首次启动将可用探索包（否则玩家包）固定在 `data/launcher.json`。后续更新不会自动切换数据包，避免账号绑定冲突。环境变量 `ASTRALOGUE_PACK` 可显式指定其他包，原有兼容检查仍执行。如果整个项目移动位置，设置 `ASTRALOGUE_HOME` 为新项目目录，或更新 `.cmd` 中的根目录路径；项目和虚拟环境仍须存在。

## LLM 交互

由 LLM 的终端工具以 PTY 模式启动同一个 `.cmd`（例如 `exec_command` 设置 `tty=true`），保存返回的 session_id；后续使用该会话的 stdin/read 接口输入与读取，直到退出。启动器不创建输出捕获管道、不重定向密码或记录输入，直接继承宿主终端句柄；Python 以无缓冲、UTF-8 模式运行。

**持久性由 PTY 宿主提供。** 启动器不是可断线重连的常驻会话服务器，关闭普通终端会结束进程。剧情进度仍按既有账号机制自动保存，重新打开可继续。运行中的 Python 进程不会热更新；更新后重新启动即加载新源码。
