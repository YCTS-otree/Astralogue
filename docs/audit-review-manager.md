- 列表展示章节、任务、小节、片段名称和实际台词预览。
- 排列优先使用已记录 Reader 路径中的位置，尚未进入已记录路径的片段使用来源小节位置。未确定的归属明确标记，不将编号或提案生成时间作为剧情顺序。

- “具体修改”只包含已绑定实际节点及可检查位置的提案；“研究结论与待定位”中的记录不能批准为播放修改，只能记为已阅、暂缓或驳回。
- 模型原始意见、来源绑定及 JSON 放在技术详情中。审批单独记录，不会直接修改已发布 StoryPack 或存档。
- 位置根据缓存来源和当前 Reader 路径展示，并不等于恢复了游戏的世界状态触发条件。跨小节或未知位置不能当作确定的插入点。
