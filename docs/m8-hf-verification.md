## 独立依据与抽样复核

- 匹配顺序：原文精确 → NFC/空格/引号及明确的全半角波浪号规范化 → 受限模糊候选。
  不改写原文、不按 ID 大小/距离排剧情、不以相似度作为正确率。
- 重复文本保留全部候选。任务成员来自旧控制图，发言名来自 TalkSentenceConfig/TextMap。
  发言名一致的消歧仍不能证明具体场景实例；结果记录选择依据和角色差异。
- 模糊检索最多保留 5 个候选，不自动接受。只有左右锚点在独立旧控制图中指向同一实际节点实例时才确认。
- 002 的 HF 条目 91 映射到 **100020340**：左右为 100020339/100020341，原文使用 {NICKNAME}，
  转录写玩家称谓。原 Act100020113 的同一 SimpleTalkList/图节点提供独立证据，不用 HF 自建边确认自身。
- 001 的条目 115 映射到 **200011602**，同样由原有局部控制节点双侧证据确认。
- 001 的“他/她”候选 **100020109 / 100020110** 保持未决，没有选择默认性别。

定向复核重复短句、模糊文本、规范化与任务边界共 8 项：6 项有独立控制/原生字段支持，0 项发现错误，
2 项实例上下文未决（包括性别候选）。支持/错误/未决比例为 75% / 0% / 25%，是有意分层样本，
**不能外推总体准确率**。只有文本相符却无法证明场景的项不会升级为 GAME_VERIFIED。
复核记录 data/hf-source-review.json；复核工具 tools/review_hf_sample.py，不是外部社群审核。
