# Full Corpus Narrative Audit — 当前验证记录

日期：2026-11-04；引擎 1.16.0。此记录区分已完成基础设施和仍需人工批准的剧情修改。

## 已实际执行

- 对 2,121 个已有来源完成确定性遍历，共 10,964,547 条来源行；其中 6,859,339 条原生资产索引行以分块哈希收据保存。目录台词、来源实例、执行实例分开记录，不能将这些数字相加作为剧情台词数量。
- 未重新扫描 ASB，也未因本轮审计发起 BWIKI 采集。既有采集进程独立运行导致快照间来源数变化；本报告以当前 SQLite 来源清单为分母。
- 第一节三阶段审计已运行：12 个结构块、30 个内容块、1 个全局复核块。202 个不同实例获得通过协议验证的内容分类，另有 2 个困难样本复核（与前述实例重叠，不能相加）。其中 146 个实例仍分类为 UNKNOWN。其他序章任务及全库后台队列不等于已经审阅。
- 原有首任务默认路径实际播放 158 条 DialogueEvent；充分探索基线 159 条，多出的仅是原先已有银狼可选互动。这是尚未清理的基线，不是本轮清理成功。
- 独立 Wiki 折叠标签及文本交叉检查发现 9 组、28 个疑似混入主线的实例。银狼同一句文本出现在不同触发上下文，不能按台词 ID 一次移动两个实例。模型复核对此生成分开的建议，仍需人工决定。

## 模型与费用

- 复用全局推理设施；2B 校准出现模板回声和无法分类，未计为有效审核。后切换中国源下载并校验的 Qwen3.5-9B-Q4_K_M，使用 llama.cpp、32K 服务上下文、单并发。
- 本机 16GB 显存环境实测 9B 服务占用约 8.1GB 显存，短输出解码约 80 token/s；排队时间与模型计算时间分别保留，不将固定 JSON 吞吐测试当作语义准确率。
- DeepSeek 使用 deepseek-flash（V4.1-Flash-1017）、低推理。累计调用上限人民币 5 元；当前按峰时未命中单价计算的费用上界为 0.615402 元，含失败请求保守预留的预算占用为 1.26952 元。不是实际账单。
- 调用记录合计 940,360 输入 token、81,419 输出 token，包含校准、失败及复核，不能当作已审阅实例数。

## 人工审核与界面修复

当前有 70 项待审核、0 项批准、0 项实际应用。新版管理器将有明确节点与位置的 10 项放在具体修改，其余 60 项放在研究结论与待定位。列表显示章节/任务/小节/文本，优先按已记录阅读路径排序；详情显示上文、原位置修改、正文及下文。没有确定位置不会编造插入点。

原始模型 JSON 收入技术详情。研究结论不能通过 HTTP 表单绕过校验批准为播放修改；记为已阅不进入 Patch 导出。

## 尚未完成

- 没有人批准提案，因此本轮未安全迁移任何实际剧情实例，也未构建宣称已清理的新发布包。尚不能断言纯主线已经排除可选对话。
- NPC/物件具体触发条件及世界状态多数未知；研究结论中的分场建议需要补全节点绑定和证据。
- 后续序章任务及全库语义队列尚未全部处理；TextMap-only 等未归属资源的后台语义覆盖仍需完善，不能宣称全库 LLM 审计完成。
